# WebhooksConfigWithSecret

A webhook configuration including its signing secret. Returned exactly once, at creation (POST /configs) and at secret rotation (PUT /configs/{id}/secret/change), so the caller can store the secret for signature verification. Never returned by read, update, activate or deactivate endpoints.
